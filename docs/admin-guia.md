# Guía rápida - Panel Configuración (V&V-Consultores)

URL: https://v-v-consultores.com/admin/ (o https://jdiazp67.github.io/Estudio-de-Abogados-Online/)

## Primer ingreso
1. Abrir sitio → pulsar botón ⚙️ (header)
2. Crear clave (mín. 4 caracteres)
3. Al guardar por primera vez solicitará GitHub PAT fine-grained (Contents: Write)

## PAT fine-grained
https://github.com/settings/tokens?type=beta
- Repositorio: solo Estudio-de-Abogados-Online
- Permissions → Repository → Contents → Write
- Guardado solo en sessionStorage (se borra al cerrar pestaña)

## Uso
- Subidas: fotos WebP ≤1600px, PDFs ≤700KB
- Staff: foto + CV PDF por profesional
- Cursos: nombre, costo, foto
- Eventos: foto temporada + destacado
