1. Introducción y objetivo del sistema

LexOnline es un sistema web estático-dinámico que digitaliza la atención de un estudio jurídico: permite al público agendar consultas legales por videollamada, inscribirse a cursos y diplomados, conocer al staff de abogados colegiados y conectarse a una sala virtual, todo gestionado mediante canales digitales (WhatsApp y Google Meet).

El objetivo funcional del sistema es servir de vitrina y canal de captación automatizado: presenta el catálogo completo generado desde un único archivo de datos y convierte cada acción del usuario (agendar, inscribirse, escribir) en un mensaje estructurado enviado por WhatsApp al estudio.

2. Alcance

  • Incluye: página única (one-page) con catálogos dinámicos, formularios con validación, modales de agendamiento e inscripción, sala virtual con acceso a Google Meet, modales legales y diseño responsive.
  • No incluye: pasarela de pagos en línea, panel administrativo, base de datos en servidor ni autenticación de usuarios. La gestión posterior (confirmación y cobro) se realiza manualmente por WhatsApp.

3. Arquitectura técnica

Aplicación de una sola página construida con HTML5 + CSS3 + JavaScript vanilla (ES6), sin frameworks ni dependencias externas. Sigue una arquitectura de tres capas:

/proyecto
├── index.html          → Estructura y secciones de la página
├── css/
│   └── estilos.css     → Presentación (paleta institucional, responsive, modales)
├── js/
│   ├── datos.js        → CAPA DE DATOS: objeto LEX (catálogo completo)
│   └── main.js         → Lógica: render dinámico, modales, validaciones, WhatsApp
└── img/                → Reservado para imágenes
CapaArchivo(s)Responsabilidad
Estructuraindex.htmlContenedores vacíos (#especialidades-grid, #cursos-grid, #staff-grid) que el JS llena; secciones, modales y formulario.
Presentacióncss/estilos.cssEstilos con variables de marca (azul marino #0B2A5B, dorado #C9A227), grillas flexibles, media queries y estados de modales/tabs.
Datosjs/datos.jsObjeto global LEX: única fuente de verdad del catálogo y datos de contacto.
Comportamientojs/main.jsIIFE que renderiza los catálogos con template literals, gestiona modales, valida formularios y arma los enlaces de WhatsApp.

8. Modelo de datos

Toda la información comercial del sistema reside en el objeto global LEX (archivo js/datos.js). Es la única fuente de verdad: la web se renderiza a partir de él.

const LEX = {
  whatsapp: "51999999999",            // Número institucional (sin "+")
  correo:   "contacto@lexonline.com",

  especialidades: [                   // Catálogo M03
    { id: "penal",                    // identificador único
      nombre: "Derecho Penal",
      descripcion: "...",             // texto de la tarjeta
      abogados: ["Dr. Luis Pérez", "Dra. María López"],
      duracion: "30 min",             // duración de la sesión
      precio: 80 },                   // precio en soles
    // ... 6 especialidades en total
  ],

  cursos: [                           // Catálogo M04
    { id: "curso-penal",
      nombre: "Derecho Penal Aplicado",
      modalidad: "Grabado | En vivo (Meet) | Híbrido",
      descripcion: "...",
      modulos: "12 videos",
      precio: 199,
      docente: "Dr. Luis Pérez" },
    // ... 4 programas en total
  ],

  abogados: [                         // Staff M05
    { nombre: "Dr. Luis Pérez",
      especialidad: "Derecho Penal",
      cal: "CAL 12345" }              // nº de colegiatura visible
    // ... 8 miembros en total
  ]
};

9. Reglas de negocio

IDRegla
RB-01Los precios se expresan en soles (S/) y están definidos únicamente en datos.js; ninguna otra parte del código contiene precios.
RB-02Solo pueden elegirse, para una cita, los abogados asignados previamente a esa especialidad en los datos.
RB-03Una solicitud de cita requiere: nombre del cliente, fecha y hora. El WhatsApp del cliente es opcional.
RB-04Una inscripción requiere nombre; el correo y WhatsApp son opcionales pero recomendados para recibir comprobante y acceso.
RB-05Un mensaje de contacto requiere nombre y mensaje; el correo es opcional.
RB-06La Sala Virtual solo acepta enlaces cuyo dominio sea meet.google.com; cualquier otro texto es rechazado con alerta.
RB-07Los pagos no se procesan dentro de la web: se coordinan por WhatsApp una vez enviada la solicitud («pagas al confirmar tu cita»).
RB-08Todos los mensajes generados (cita, inscripción, contacto) se dirigen al número institucional LEX.whatsapp, nunca a números ingresados por el usuario.
RB-09Las consultas constituyen orientación profesional y no sustituyen patrocinio formal; esta advertencia figura en el aviso legal del modal y en los Términos y Condiciones.
